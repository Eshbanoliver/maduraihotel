## 🌟 Key Features & Sections
- **Brand Story & About Us:** Verbatim preserved content showcasing family-run hospitality and hotel history.
- **Accommodations (3 Categories):**
  - **Super Deluxe Room:** High ceilings, wood finishings, couple accommodation, tea maker, LED TV, separate shower.
  - **Triple Bed Room:** Warm tones, triple bedding / king bed, split AC, 24h laundry, station transfers.
  - **Deluxe Room:** Scenic Udaipur views, practical comfort, high-speed WiFi, essential toiletries.
- **Hotel Facilities:** Split AC, LED satellite TV, private bathrooms with hot/cold shower, high-speed WiFi, lift/elevator across all floors, 24h laundry, railway station/airport transfers, and travel desk.
- **Dining & Restaurant:** Cozy breakfast room serving rich continental breakfast and renowned traditional Family Thalis near Udaipur Station.
- **Restaurant Menu:** Transparent daily seasonal specials with direct WhatsApp inquiry functionality.
- **Underground Bar:** Subterranean evening lounge experience for beverages and relaxation.
- **Photo & Video Gallery:** 100% genuine original Hotel Madurai photography with interactive lightbox modal.
- **Real Testimonials:** Original unedited reviews from Sapna (Delhi), Shivani (Dehradun), and Ashok (Jaipur).
- **Location & Nearby Attractions:** Interactive Google Maps, transit times to Udaipole Bus Stand and Udaipur Railway Station, plus Fateh Sagar Lake and Sahelion Ki Bari.
- **Seamless Booking & WhatsApp:** Direct integration with eGlobe Solutions booking system and room-specific WhatsApp enquiry prefilled messages.

## 🛠️ Tech Stack
- **Framework:** React 19 + TypeScript
- **Styling:** Tailwind CSS + Custom Editorial Design System
- **Icons:** Lucide React
- **Routing:** React Router v7
- **Build Tool:** Vite

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
